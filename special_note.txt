when you need gallery page,
    1. create src/pages/GalleryPage.tsx that renders <GallerySection /> (src/sections/GallerySection.tsx)
    2. add a route in src/App.tsx:      <Route path="gallery" element={<GalleryPage />} />
    3. add a nav item in src/constants/routes.ts:  { path: '/gallery', label: 'Gallery' }

blog posts:
    add a Markdown file to src/content/blog/ (copy the frontmatter from resumelog.md).
    covers live in public/illustrations/ (cover: file-name.png).
